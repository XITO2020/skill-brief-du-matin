# skill-brief-du-matin

`tv1e-0006` - skill Claude Code du catalogue tv1e (tuveuxun.expert/skills). Gratuit, licence MIT.

## Installation

Copier le dossier dans `~/.claude/skills/brief-du-matin/` (ou `.claude/skills/brief-du-matin/` d'un projet), en gardant le fichier `SKILL.md` a la racine du dossier.

Le skill s'active tout seul quand la demande correspond a sa description (premier bloc de `SKILL.md`).
